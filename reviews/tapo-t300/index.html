Qué es y cómo avisa

El Tapo T300 es un sensor inteligente de fugas de agua que detecta agua mediante seis sondas, situadas en la parte superior e inferior del dispositivo. TP-Link lo plantea para puntos como fregaderos, lavadoras, baños y otras zonas donde una fuga pueda aparecer.

El T300 necesita un Tapo Hub. El sensor utiliza la banda Sub-1G especificada para la versión regional y el hub es el elemento que concentra los accesorios y permite gestionar el sistema desde la aplicación Tapo. En la versión europea, TP-Link especifica 868 MHz para la comunicación inalámbrica del sensor.

Cuando detecta agua, el propio sensor puede emitir una alarma de hasta 90 dB. TP-Link también documenta que el hub puede activar su propia alarma y que una Smart Action puede utilizar el T300 como disparador para determinadas acciones locales cuando la configuración es compatible.

El sensor funciona con dos pilas AAA reemplazables. TP-Link anuncia hasta tres años de autonomía, aunque la documentación aclara que la duración real depende de las condiciones de trabajo y del entorno. En su FAQ también publica una cifra de hasta 1,5 años cuando el sensor coordina alarmas del hub 24/7 bajo un escenario de laboratorio concreto. Y la hoja de especificaciones oficial (datasheet EU/US 1.0) indica «1 año o más». Tres cifras distintas del mismo fabricante: la más prudente es la del datasheet. No tratamos ninguna como autonomía medida por Casa Bajo Control.

Qué pasa cuando algo falla

01

Sin Internet con el router encendido

El punto importante es el hub. TP-Link documenta que determinadas Smart Actions pueden ser asumidas por el hub y continuar ejecutándose durante fluctuaciones de red o desconexiones temporales. Eso significa que algunas automatizaciones locales pueden mantenerse, pero no equivale a garantizar que una notificación llegue al móvil desde fuera de la vivienda.

02

Router apagado

Si el router deja de estar disponible, la parte del sistema que depende de la red exterior deja de tener el mismo camino de comunicación. La alarma local del sensor y las automatizaciones que gestione el hub son una capa distinta del aviso remoto. El comportamiento exacto y la recuperación son cosas que todavía debemos medir.

03

Corte de luz

El T300 funciona con pilas, pero el Tapo Hub necesita alimentación eléctrica. Por eso, una casa sin corriente puede conservar el sensor con batería y, al mismo tiempo, perder el elemento que concentra la instalación y comunica con el exterior. La documentación no nos permite convertir esa situación en un resultado de prueba.

04

Batería baja

TP-Link indica que el T300 muestra un aviso de batería baja cuando la energía cae por debajo del 20 %. La aplicación puede mostrar un recordatorio y una barra de batería restante. Aún no hemos medido cuánto dura una pareja de pilas en nuestro escenario real.

Para nosotros, este es el matiz clave: el T300 puede formar parte de una arquitectura con automatizaciones locales, pero el aviso remoto depende de que el resto de la cadena siga disponible. Si tu prioridad es entender qué ocurre cuando falla Internet, explicamos las cuatro arquitecturas en nuestra guía de detectores de fugas sin Internet.

Dependencias y coste total

El Tapo T300 no es un sensor independiente. Hay que contar con un Tapo Hub compatible y con la aplicación Tapo para configurar y gestionar el sistema. TP-Link también utiliza un TP-Link ID para las funciones de gestión y nube del ecosistema.

Esto cambia bastante el coste y la arquitectura respecto a un sensor que se conecta directamente por Wi‑Fi. La ventaja es que el hub permite centralizar varios accesorios Tapo y asumir determinadas automatizaciones localmente; la desventaja es que añade otro equipo que necesita estar correctamente instalado y alimentado.

No hemos encontrado en la documentación consultada una suscripción obligatoria para las funciones básicas del T300, por lo que no añadimos un coste periódico que el fabricante no especifique para este uso.

Para...

  • una segunda residencia donde el hub pueda quedarse sin alimentación;
  • quien no quiera depender de un hub adicional;
  • quien necesite una vía móvil independiente del router;
  • quien quiera una solución cuyo funcionamiento remoto no dependa de la conectividad de la vivienda.

En una vivienda cerrada durante semanas, el sensor es solo una pieza de la cadena. Explicamos cómo valorar esa cadena en nuestra guía sobre cómo proteger una segunda residencia cuando estás lejos.

Lo que solo sabremos al probarlo

  • Tiempo hasta la alerta: desde que aparece agua hasta que llega el aviso al móvil.
  • Sin Internet con el router encendido: qué detección y automatizaciones permanecen disponibles.
  • Router apagado: qué ocurre con la alarma local, el hub y la recuperación posterior.
  • Corte de luz: qué mantiene el T300 con sus pilas y qué pierde el sistema al apagarse el hub.
  • Autonomía real: evolución de las dos pilas AAA en nuestro escenario.
  • Falsas alarmas: comportamiento ante salpicaduras, humedad persistente y condensación.

TP-Link proporciona cifras de batería y describe funciones de alarma y automatización, pero todavía no tenemos datos propios sobre el tiempo real de alerta ni sobre la recuperación después de una interrupción de red o alimentación.

Preguntas frecuentes

¿El Tapo T300 funciona sin Internet?

El sensor necesita un Tapo Hub y TP-Link documenta automatizaciones que pueden ser ejecutadas por el hub durante fluctuaciones de red o desconexiones temporales. Eso no significa que el aviso remoto al móvil siga funcionando sin conexión exterior. Para una respuesta definitiva sobre cada escenario de corte necesitamos probar la unidad.

¿Necesita hub?

Sí. TP-Link especifica que el Tapo T300 requiere un Tapo Hub. El sensor se comunica con el hub y desde ahí se gestiona el sistema en el ecosistema Tapo.

¿Suena si detecta agua?

Sí. TP-Link especifica una alarma de hasta 90 dB en el T300. Además, el hub puede activar su propia alarma cuando se detecta una fuga.

¿Sirve para una segunda residencia?

Puede tener sentido si ya tienes o quieres montar un ecosistema Tapo y puedes mantener el hub correctamente alimentado y conectado. Si necesitas una vía móvil independiente cuando falle el router o Internet, deberíamos valorar otra arquitectura.
