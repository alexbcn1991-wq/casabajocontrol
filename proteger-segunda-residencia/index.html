Cómo preparar una segunda residencia antes de dejarla vacía

Una lista práctica para revisar agua, humedad, conectividad y temperatura antes de marcharte durante días o meses.

1. Agua

Empieza por las zonas con mayor riesgo de fuga: cocina, baños, lavadora, termo y puntos de entrada de agua. Un detector sirve para avisar; no sustituye una revisión de la instalación ni una solución de corte cuando sea necesaria.

2. Humedad

Un sensor de humedad puede ayudarte a detectar cambios anómalos antes de que sean visibles. En viviendas cerradas durante mucho tiempo, interesa conocer el comportamiento habitual de cada estancia y no interpretar una lectura aislada sin contexto.

3. Conectividad

Antes de confiar en una alerta remota, comprueba qué ocurre si se pierde Internet o la alimentación eléctrica. Una solución para una vivienda vacía debe tener claro qué puede detectar y comunicar cuando algo falla.

4. Temperatura

Las temperaturas extremas pueden afectar a instalaciones y estancias. Un sensor con historial y alertas puede ser útil para detectar una situación que no sería visible hasta tu próxima visita.
